# Baza danych sklepu wędkarskiego

Ten folder zawiera strukturę i dane startowe bazy sklepu.

## Pliki

- `schema.sql` - tworzy tabele i relacje bazy danych.
- `seed.sql` - dodaje początkowe kategorie sklepu.

## Główna struktura kategorii

- Przynęty
  - Gumy
    - Kopyta
    - Twistery
- Sprzęt
- Narzędzia

Baza jest przygotowana pod PostgreSQL.

Nie przechowujemy tutaj haseł, kluczy API ani innych sekretów.
